# PRODUCT REQUIREMENTS DOCUMENT (PRD)
## Website Statis Multi-Halaman: MinchaLoved – Fashion Preloved

### 1. Informasi Proyek
**Nama Startup:** MinchaLoved
**Produk/Jasa:** Fashion Preloved
**Tujuan:** Memperkenalkan brand, menampilkan katalog, mempermudah pembelian via WhatsApp, dan membangun kepercayaan dengan tampilan profesional & feminin.

### 2. Target Pengguna
Wanita usia 18–35 tahun, mahasiswa/pekerja muda, menyukai fashion terjangkau, aktif di media sosial, menyukai estetika.

### 3. Struktur Halaman
1. **Beranda (Home):** Identitas, banner, produk unggulan, testimoni.
2. **Tentang Kami:** Cerita brand, visi misi, komitmen kualitas.
3. **Produk:** Katalog grid (Foto Polaroid style, Nama, Harga, Ukuran, Kondisi).
4. **Detail Produk:** Galeri, deskripsi lengkap, stok, aksi (WA/Keranjang).
5. **Keranjang:** Daftar belanja, total, checkout format WA.
6. **FAQ:** Accordion (Originalitas, kondisi, cara beli, dll).
7. **Kontak:** WhatsApp, Instagram, Email, Maps.

### 4. Design System
*   **Warna:** 
    *   Background: #FFD6F0 (Ungu Muda)
    *   Primary: #69495D (Ungu)
    *   Accent: #B99F56 (Kuning Emas)
    *   Support: #C6A898 (Nude), Coklat Muda
    *   Text: #3D293E (Heading), #805770 (Body)
*   **Tipografi:**
    *   Heading: Playfair Display (Elegan)
    *   Body: Poppins (Modern)
*   **Visual Style:** 
    *   Background motif gantungan baju transparan.
    *   Ilustrasi bunga line art, kupu-kupu, brush strokes.
    *   Foto produk bergaya Polaroid.
    *   Sudut membulat (20-24px), soft shadows.

### 5. Fitur Utama
*   Checkout via WhatsApp dengan format pesan otomatis.
*   Grid produk responsif.
*   Floating WhatsApp button.
